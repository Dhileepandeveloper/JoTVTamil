# Simple E-commerce Store (Express + LowDB)

- Frontend: HTML, CSS, JavaScript (served from `public/`)
- Backend: Express.js (Node)
- Database: LowDB (JSON file at `data/db.json`)

## Quick Start
```bash
npm install
npm run seed
npm run dev
# open http://localhost:3000
```
